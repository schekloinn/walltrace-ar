# WallTrace AR 1.1 — готова IPA

- Версія 1.1 (2), iPhone arm64, iOS 15.0+.
- До трьох окремо закріплених PNG; власні ширина й непрозорість для кожного.
- Кнопка ока приховує/повертає панелі.
- Згладжування малих корекцій, захист від великих нестабільних стрибків і надмірного наближення.
- «Зберегти» записує ARWorldMap, PNG, якорі та параметри; після повернення запускається автоматичне відновлення останньої сцени в тій самій кімнаті.
- Репозиторій: https://github.com/schekloinn/walltrace-ar
- Успішна CI-збірка: https://github.com/schekloinn/walltrace-ar/actions/runs/40587160572
- Коміт коду: `f804813b54c830a8c91490be28cab5c2d4c3d7be`.
- Xcode 16.4 / SDK 18.5 / XcodeGen 2.46.0. Host checks слотів, стабілізації та збереження пройшли; device build, ad-hoc codesign verify й ZIP CRC пройшли.
- IPA: `WallTraceAR-1.1.ipa`, 108497 байтів.
- SHA-256: `31da11dc471af4ad23614db020c5d43c6162e128b3ed3e5468d59f3a6265ca6a`.

Встановити через TrollStore поверх попереднього WallTrace AR. Для збереження перед виходом натиснути «Зберегти» й дочекатися підтвердження. Після повернення показати ту саму стіну — картинки з’являться після relocalization.

На реальному iPhone нова версія ще не тестувалася. ARKit може не впізнати змінену/погано освітлену кімнату; стабілізатор пом’якшує показ корекцій, але не гарантує відсутності дрейфу. Деталі та приймальні сценарії — у `VALIDATION.md`.
