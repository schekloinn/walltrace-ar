# Puffline

Самостійний український трекер поступового скорочення вейпінгу для iPhone, iOS 15.0+.
Назва англійською, інтерфейс українською. Мінімалістична чорно-біла палітра.

Реалізовано: ручний облік і пакетне додавання, скасування останньої дії, історія з видаленням,
персональний план, адаптивний/фіксований темп, пауза, тижневі/місячні графіки,
статистика за годинами, календар, орієнтовна економія, відлік без вейпу, хвилина паузи,
локальне щоденне нагадування, світла/темна/системна тема, тактильний відгук,
JSON резервні копії та відновлення, CSV, малий/середній віджет, URL-команди і швидка дія іконки.

## Поточний етап

Користувач переглянув скриншоти й схвалив створення IPA.
Workflow build-ipa.yml збирає Release arm64 для iPhone/iOS 15.0+, підписує застосунок і віджет та перевіряє пакет.
Workflow preview.yml запускається вручну й створює лише Debug-скриншоти симулятора.
Демонстраційна історія в DemoData.swift існує лише для DEBUG і аргументу --preview.
Release ніколи не завантажує ці приклади.

## Перевірки та обмеження

Початковий ліміт: 1–5000, тривалість: 7–365 днів. Крок = округлення вгору baseline/duration,
тому прогноз може бути коротшим за обрану тривалість. Пропущений день утримує ліміт,
а не вважається успішним. Перевищення утримує ліміт за адаптивного темпу.
Історичні ліміти фіксуються. Зміна плану зберігає історію; оцінка економії відтепер використовує нову базу.
Сповіщення залежать від дозволу iOS; час фонового оновлення віджета визначає система.
На iOS 15 віджет відкриває застосунок, додавання підтверджується там.
Команди: URL + Відкрити URL, адреса puffline://add?count=1.
Немає автоматичного визначення затяжок, серверів, реклами, платежів чи медичних прогнозів.
Реальне встановлення через TrollStore, віджети та сповіщення на фізичному iOS 15.8.7 поки не перевірено.

Локальне збирання IPA на Mac із Xcode 16.4 та XcodeGen: `bash scripts/build-ipa.sh`.
Результат: build/Puffline-1.0.ipa і SHA-256. Ad-hoc підпис означає codesign identity «-», не Apple Ad Hoc distribution.
TrollStore перепідписує пакет під час встановлення. Передай IPA на iPhone: «Поділитися» → TrollStore → Install.
Повторна перевірка пакета: `python3 scripts/validate-ipa.py build/Puffline-1.0.ipa`.
Модель: xcrun swiftc Shared/Model.swift Tests/Checks.swift -o checks && ./checks.
