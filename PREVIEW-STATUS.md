# Перегляд перед IPA

2026-11-03. За проханням користувача IPA ще не створювався: спочатку скриншоти й відгук про вигляд.

Успішна збірка для симулятора: https://github.com/schekloinn/walltrace-ar/actions/runs/41640091219
Знімки: iPhone SE (3rd generation), iOS 18.6, екран 375×667 pt.
Мінімальний deployment target застосунку й віджета: iOS 15.0.
30 host-перевірок моделі пройшли. Головний екран, прогрес, налаштування, екран паузи й темну тему переглянуто візуально.
На знімках DEBUG використовуються демонстраційні записи; їх немає у звичайному Release.

Після знімків локально виправлено округлення відсотка: 144 / 180 має показувати зниження 20%, а не 19% через похибку Double.
Цю однорядкову зміну потрібно включити в наступну збірку після відгуку про дизайн.

Далі: врахувати правки користувача, перевірити основні взаємодії й Release arm64,
підготувати IPA з підписом для TrollStore, перевірити пакет, передати інструкцію встановлення.
Встановлення на фізичний iPhone з iOS 15.8.7, сповіщення та обмін із віджетом поки не перевірені.
