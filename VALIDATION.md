## Локальні перевірки на Windows

YAML розібрано PyYAML із перевіркою дублікатів ключів, plist — `plistlib`, Swift і Bash — Tree-sitter без синтаксичних помилок. Є 48 незалежних числових перевірок базису розміщення; тестовий PNG перевірений як RGBA. Вихідний ZIP містить `.github/workflows`, перевіряється на CRC і точну відповідність вихідній папці. Після публікації також порівнюються Git blob hashes локальних і віддалених файлів.

Валідатори Windows — лише в `work`, не runtime-залежності програми. Swift host checks виконує лише тести моделей і математики; app залежить лише від системних Apple framework.

## Що ще потребує iPhone

**Не перевірено на фізичному iPhone 7 / iOS 15.8.7:** UI й кнопка ока, імпорт із file providers, три одночасні AR-картинки, відчуття плавності й продуктивність, фактичний ефект захисту біля стіни, реальний `getCurrentWorldMap`, збереження/відновлення кімнати, relocalization після фону чи завершення програми та встановлення через TrollStore.

Фільтр не виправляє помилкову оцінку позиції камери ARKit. При надмірному наближенні або ненадійному tracking програма тимчасово ховає накладання. Відновлення збереження потребує впізнавання тієї самої кімнати; успішна компіляція цього не гарантує.

## Приймальний тест на телефоні

1. Оновити застосунок IPA 1.1 через TrollStore; дозволити камеру.
2. У слотах 1, 2, 3 імпортувати різні PNG й розмістити їх на стінах. Перевірити, що масштаб, прозорість, заміна, переміщення й видалення одного не зачіпають інших.
3. Сховати UI кнопкою ока: усі накладання мають лишитися; маленька кнопка повертає панелі.
4. Підійти ближче ніж на 20 см: відповідне зображення має сховатися, підказка — попросити відійти. Відійти за 30 см: після стабілізації воно з’являється. Перевірити, що інші слоти зберігаються.
5. Оглянути деталі кімнати, дочекатися активної «Зберегти», натиснути й дочекатися підтвердження. Піти у фон, повернутися й навести на попередню стіну: після normal tracking перевірити ті самі три місця, розміри й прозорість.
6. Повторити після повного завершення програми. Також перевірити «Відновити», невпізнану кімнату, зміну освітлення та можливість «Скинути AR».
7. Перевірити скасування/помилки імпорту, відмову камері, тривалу сесію, нагрівання, системне переривання та повідомлення про невдале збереження без втрати попередньої копії.
